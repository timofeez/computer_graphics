# Чеклист выполнения лабораторной работы №2

## Базовое условие

### ✅ 1. Программа работает в реальном времени, с возможностью взаимодействия с камерой с помощью клавиатуры и мыши без использования UI-элементов
- **Статус**: ✅ ВЫПОЛНЕНО
- **Реализация**: 
  - ESC - переключение захвата мыши
  - WASD - движение камеры (когда мышь захвачена)
  - Мышь - поворот камеры (когда мышь захвачена)
  - Space/Shift - вверх/вниз
  - Управление работает без UI элементов

### ✅ 2. Для точечных источников света используются shader-storage буферы
- **Статус**: ✅ ВЫПОЛНЕНО
- **Реализация**:
  - `point_lights_buffer` создан с `VK_BUFFER_USAGE_STORAGE_BUFFER_BIT`
  - В дескрипторе используется `VK_DESCRIPTOR_TYPE_STORAGE_BUFFER`
  - В шейдере используется `layout (binding = 3, std430) readonly buffer PointLightsBuffer`

### ✅ 3. UI элементы для управления параметрами источников света в реальном времени
- **Статус**: ✅ ВЫПОЛНЕНО
- **Реализация**:
  - Рассеянное освещение: ColorEdit3, SliderFloat для ambient_color и ambient_intensity
  - Направленное освещение: InputFloat3 для direction, ColorEdit3 для color, SliderFloat для intensity
  - Точечные источники: InputFloat3 для position, ColorEdit3 для color, SliderFloat для intensity
  - Все параметры обновляются в реальном времени

### ✅ 4. У вершин есть атрибут нормали для аппроксимации нормали гладких поверхностей
- **Статус**: ✅ ВЫПОЛНЕНО
- **Реализация**:
  - Структура `Vertex` содержит `veekay::vec3 normal`
  - В вершинном шейдере нормали трансформируются через обратную транспонированную матрицу модели
  - Нормали нормализуются в вершинном и фрагментном шейдерах

### ✅ 5. Для каждого источника света реализована модель Блинн-Фонга
- **Статус**: ✅ ВЫПОЛНЕНО
- **Реализация**:
  - Функция `blinnPhong()` в фрагментном шейдере
  - Используется для рассеянного освещения (ambient - только цвет, без Блинн-Фонга)
  - Используется для направленного освещения (directional)
  - Используется для точечных источников света (point lights)
  - Формула: diffuse = albedo * light_color * intensity * max(dot(normal, light_dir), 0)
  - Формула: specular = specular_color * light_color * intensity * pow(max(dot(normal, half_dir), 0), shininess)

### ✅ 6. У моделей есть свойства материалов: альбедо, specular, shininess
- **Статус**: ✅ ВЫПОЛНЕНО
- **Реализация**:
  - Структура `Material` с полями: `albedo`, `specular`, `shininess`
  - Структура `ModelUniforms` содержит: `albedo_color`, `specular_color`, `shininess`
  - Все модели инициализированы с разными значениями материалов

## Вариант 1

### ✅ 1. Матрица камеры рассчитывается с помощью матрицы трансформации камеры (положения и ориентации/поворота)
- **Статус**: ✅ ВЫПОЛНЕНО
- **Реализация**:
  - Метод `Camera::view()` использует:
    - `mat4::translation(-position)` - трансформация положения
    - `mat4::rotation()` для осей X, Y, Z - трансформация ориентации/поворота
  - НЕ используется Look-At матрица

### ✅ 2. Рассеянное освещение (ambient)
- **Статус**: ✅ ВЫПОЛНЕНО
- **Реализация**:
  - `LightingUniforms` содержит `ambient_color` и `ambient_intensity`
  - В шейдере: `ambient = albedo_color * ambient_color * ambient_intensity`
  - UI элементы для управления

### ✅ 3. Направленное освещение (directional)
- **Статус**: ✅ ВЫПОЛНЕНО
- **Реализация**:
  - `DirectionalLight` структура с `direction`, `color`, `intensity`
  - В шейдере применяется модель Блинн-Фонга
  - UI элементы для управления

### ✅ 4. Точечные источники света (point lights)
- **Статус**: ✅ ВЫПОЛНЕНО
- **Реализация**:
  - `PointLight` структура с `position`, `color`, `intensity`
  - Используется shader-storage буфер (`point_lights_buffer`)
  - В шейдере цикл по всем точечным источникам
  - UI элементы для управления каждым источником

### ✅ 5. Точечные источники света теряют интенсивность по закону обратных квадратов
- **Статус**: ✅ ВЫПОЛНЕНО
- **Реализация**:
  - В шейдере: `float distance = length(light_dir);`
  - `float attenuation = 1.0 / (distance * distance);` - закон обратных квадратов
  - Применяется: `light.intensity * attenuation`
